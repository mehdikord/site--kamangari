# دخانیات کمانگری

نسخه‌ی نمایشی فروشگاه اینترنتی دخانیات کمانگری با Next.js 16، React 19، Tailwind CSS 4 و shadcn/ui.
داده‌ها mock هستند، دیتابیس و API ندارد و روی سرور Node.js اجرا می‌شود (static export نیست).

> **پیش از انتشار عمومی:** ماده ۳ قانون جامع کنترل و مبارزه ملی با دخانیات تبلیغ دخانیات را ممنوع می‌کند و ماده ۱۰ آیین‌نامه‌ی اجرایی آن، فروش اینترنتی محصولات دخانی را. نحوه‌ی عرضه‌ی سیگار، تنباکو و توتون باید با مشاور حقوقی نهایی شود. تا آن زمان `demo.noIndex` روشن بماند.

## اجرا

به Node.js 22 یا بالاتر نیاز است.

```bash
npm ci
npm run dev                     # توسعه: http://localhost:3000
npm run build                   # خروجی کامل در .next/standalone
PORT=3000 npm start             # اجرای نسخه‌ی production
npm run lint
npm run typecheck
```

## سرویس لینوکس (systemd)

Node باید سراسری نصب شده باشد (نه با nvm داخل home)، چون سرویس به home دسترسی ندارد.

```bash
npm ci
npm run build
sudo ./deploy/install.sh
```

اسکریپت کاربر سیستمی `kamangiri` می‌سازد، هر نسخه را در `/opt/kamangiri/releases` می‌گذارد، سرویس را فعال می‌کند و اگر health check شکست بخورد به نسخه‌ی قبل برمی‌گردد. سه نسخه‌ی آخر نگه داشته می‌شود. برای به‌روزرسانی همین سه دستور را دوباره اجرا کنید.

```bash
systemctl status kamangiri
journalctl -u kamangiri -f
sudo systemctl restart kamangiri
```

سرویس روی `127.0.0.1:3000` گوش می‌دهد. برای تغییر، فایل `/etc/kamangiri.env` بسازید:

```ini
PORT=3100
HOSTNAME=127.0.0.1
```

بعد سرویس را restart کنید. نمونه‌ی تنظیم Nginx در `deploy/nginx.conf.example` است و برای HTTPS می‌توانید از certbot استفاده کنید.

## چه چیزی کجاست

| موضوع | مسیر |
| --- | --- |
| تلفن، پیام‌رسان‌ها، نشانی، شعار، تنظیمات دمو | `src/config/site.ts` |
| محصولات، قیمت‌ها، موجودی | `src/data/catalog.ts` |
| دسته‌بندی‌ها | `src/data/categories.ts` |
| نظرها، سوالات متداول، قوانین | `src/data/content.ts` |
| کد تخفیف، روش و هزینه‌ی ارسال | `src/lib/pricing.ts` |
| فیلتر و مرتب‌سازی | `src/lib/shop-query.ts` |
| سبد، ورود و سفارش mock | `src/lib/store.ts` |
| رنگ‌ها، اندازه‌ی تیترها و توکن‌های طراحی | `src/app/globals.css` |
| مدل سه‌بعدی قلیان | `src/three` |

عکس هر محصول در `src/data/images.json` ثبت شده و فایل‌ها در `public/images/catalog` هستند.

## زبان طراحی و لحن

- مدرن و جمع‌وجور: سفید، گرافیتی و نارنجی، بدون نقش‌مایه‌ی سنتی.
- فونت تیتر «استعداد» و فونت متن «وزیرمتن». تیتر سکشن حداکثر ۲۲ و تیتر صفحه حداکثر ۲۸ پیکسل است (`title-section` و `title-page`).
- متن‌ها رسمی و با خطاب «شما» نوشته می‌شوند. عنوان سکشن‌ها توصیفی است، مثل «دسته‌بندی‌ها».

## پیش از تحویل نهایی

- اطلاعات تماس، قیمت، موجودی و ادعاهای خدمات (ضمانت، بیمه، ۲۴/۷) را مجموعه تأیید کند.
- پیام‌های مشتریان و نظرهای محصولات ساختگی و نمونه‌اند و باید با نظر واقعی جایگزین شوند.
- بسته‌های تنباکو، توتون و زغال با برند کمانگری، رندر فرضی‌اند و باید عکس کالای واقعی جایشان بیاید.
- عکس سیگارها از ویکی‌انبار است و با بسته‌بندی بازار ایران (هشدار تصویری) یکی نیست. عکس برخی لوازم هم مدل مشابه است.
- صفحه‌ی `/credits` را تا وقتی عکس‌های Creative Commons استفاده می‌شوند نگه دارید.
- پیامک، درگاه پرداخت، احراز سن واقعی و ذخیره‌ی سفارش نیازمند backend هستند. قیمت و تخفیف باید در سرور دوباره محاسبه شود.
